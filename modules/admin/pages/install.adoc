[#windows-server]
== Установка модуля на сервер под управлением Windows

. Запустите пакет установки `{dv} ArchiveManagement.msi`.
. В приветственном окне мастера установки нажмите *Далее*.
+
.Мастер установки модуля "{am}"
image::install-server-hello.png[Мастер установки модуля "{am}"]
+
. Выберите компоненты, которые требуется установить и нажмите *Далее*.
+
.Выбор устанавливаемых компонентов
image::install-server-components.png[Выбор устанавливаемых компонентов]
+
****
Общие компоненты::
Обеспечивают взаимодействие с другими сервисами {dv}, обязательны для установки на сервер {dv} и сервер {wc}а.

Серверные компоненты:::
Основные серверные компоненты модуля _{am}_, обязательны для установки на сервер {dv}.

Кнопка Сброс::
Сбрасывает выбор компонентов на стандартные.

Кнопка Использование диска::
Позволяет посмотреть свободное место на системных дисках.
****
+
include::new-admin-console@platform:admin:partial$install-components.adoc[]
+
. Примите условия лицензионного соглашения для продолжения установки и нажмите *Установить*.
+
.Условия лицензионного соглашения
image::install-server-license.png[Условия лицензионного соглашения]
+
. Нажмите кнопку *Готово*, чтобы закрыть мастер установки.

=== Установка расширения {am} {wc}а на сервер под управлением Windows

Начиная с версии {am-cu-mc}, вместо установки расширения {am} {wc}а на сервер под управлением Windows достаточно выбрать _Общие компоненты_ при запуске основного инсталлятора модуля на сервере {wc}а.

.Чтобы установить "Общие компоненты" модуля {am}:
. Запустите пакет установки `{dv} ArchiveManagement.msi`.
. Примите условия лицензионного соглашения, чтобы продолжить установку.
. На шаге выбора компонентов выберите только _Общие компоненты_ и нажмите *Далее*.
+
.Выбор устанавливаемых компонентов
image::install-server-components.png[Выбор устанавливаемых компонентов]
+
. Нажмите на кнопку *Установить* и дождитесь завершения установки модуля.
. Нажмите на кнопку *Готово*, чтобы закрыть мастер установки.
+
include::new-admin-console@install-linux:ROOT:partial$restart-and-db.adoc[]
