= Справочник номенклатуры дел

include::6.1@webclient:user:partial$excerpts.adoc[tags=noam]

ЭУ `_Справочник номенклатуры дел_` предназначен для работы администраторов. Справочник открывает возможности создания иерархической структуры разделов для xref:user:cases.adoc#createCase[создания]
создания дел и xref:guide-add-case-control.adoc[списания] документов в дело, просмотра документов, списанных в дело.

.Представление "Справочника номенклатуры дел"
image::6.1@webclient:layouts:nomenclature-directory.png[Представление "Справочника номенклатуры дел"]

[NOTE]
====
Элемент управления становится доступным только после установки компонентов модуля _{am}_.
====
